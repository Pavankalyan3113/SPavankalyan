Code

Two practice snippets that show how I approach production and quality data. They are samples, not client work.

SQL · defect rate by machine
SELECT machine_id,
       COUNT(*) AS inspected,
       SUM(is_defect) AS defects,
       ROUND(100.0 * SUM(is_defect) / COUNT(*), 2) AS defect_pct
FROM inspections
GROUP BY machine_id
ORDER BY defect_pct DESC;
Python · daily reject rate
import pandas as pd

df = pd.read_csv("production.csv", parse_dates=["date"])
daily = df.groupby("date").agg(units=("units", "sum"),
                               rejects=("rejects", "sum"))
daily["reject_pct"] = (daily.rejects / daily.units * 100).round(2)
print(daily.tail())
